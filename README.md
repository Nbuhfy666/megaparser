# MegaParser [RUS]
**MegaParser (MP) - самый лучший парсер для Python.**
**Создан для легкой работы с:**
* Файлами
* Web (Сайты, Браузер)
* Возвращения текста
* Рандомизации
* Временем
* Типов (для писания)
**Версии:** 
mp.<цифра_по_английски>
**Патчи:**
mp.<версия>.<цифра>

**Пример версий:**
* mp.one
**Пример патчей:**
* mp.one.1
